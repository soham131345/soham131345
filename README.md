## Hello, I’m Soham

I’m a student developer based in Singapore who enjoys turning ambitious ideas into useful systems. My work moves between full-stack web applications, machine-learning research, developer tools and connected hardware. I also publish independent research and compete in hackathons and technical competitions.

> Most of my projects are proprietary. My public GitHub contains a selection of the tools, research and experiments I can share.
